# Посмотри в окно

Учебный проект третьего спринта курса «Фронтенд-разработчик» в Яндекс Практикуме.

**«Посмотри в окно»** — веб-приложение для просмотра видео с видами из окон разных городов. Пользователь может выбирать видео с помощью формы поиска и просматривать подходящие результаты.

## Технологии

- HTML5
- CSS3
- JavaScript
- Git и GitHub

## Функциональность

- Просмотр видео.
- Поиск и фильтрация видео по заданным параметрам.
- Взаимодействие с элементами интерфейса.

## Запуск проекта

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/taisiapilipchuk/posmotri-v-okno-ad.git
   ```

2. Перейдите в папку проекта:

   ```bash
   cd posmotri-v-okno-ad
   ```

3. Откройте файл `index.html` в браузере или запустите проект с помощью локального сервера.

## Статус проекта

Учебный проект. Выполнен в рамках третьего спринта Яндекс Практикума.
